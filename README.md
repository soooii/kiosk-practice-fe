# AI 키오스크 체험

스마트폰과 키오스크 조작이 익숙하지 않은 분을 위한 브라우저용 React 연습 서비스입니다. 메가커피 주문, 맥도날드 주문, CGV 영화 예매, 다이소 셀프계산대를 체험할 수 있습니다.

각 화면의 AI 도움말에서 기본 안내를 보거나 현재 버튼에 대한 AI 설명을 요청할 수 있습니다. 모의 결제가 끝나면 선택 기록과 학습 기록으로 피드백을 받고, 홈의 학습 리포트에서 지난 연습을 확인합니다. 메뉴 가격과 상영 정보는 연습용이며 실제 결제는 없습니다.

```sh
npm ci
npm run dev
```

배포용 빌드는 `npm run build`로 생성하고, `npm run preview`로 확인합니다.

## 카페·다이소 연습

홈 → 체험 시작하기 → 카페 주문 또는 마트 셀프계산대에서 실행합니다.

- 카페: 메뉴 분류/페이지, 온도 선택, 수량, 장바구니 추가·수정·삭제, 결제 방법, 주문 확인, 해설 및 완료 화면
- 다이소: 상품 버튼으로 스캔 시뮬레이션 → 실제 목록 비교 → 수세미 3개를 2개로 수정 → 봉투 선택 → 카드 결제 연습 → 해설 및 완료
- 수세미 2개(각 1,000원), 테이프 1개(2,000원), 건전지 1개(1,000원)이며 소형 봉투를 선택하면 합계 5,100원입니다.
- 주문 상태는 React 메모리에 저장하며 새로고침·처음으로·다시 연습하기 시 초기화됩니다. 완료한 학습 기록은 이 브라우저에 최근 20회까지 저장합니다. DB나 결제 API는 사용하지 않습니다.
- 첨부 시안의 색상, 세로형 구성, 큰 버튼과 단계별 화면을 반영했습니다. 상품과 단말기는 외부 이미지 요청 없이 CSS/문자로 표현한 연습용 일러스트입니다. 가격은 연습용입니다.

검증: `npm test` (장바구니 병합·온도별 분리·합계·중복 수정·봉투 금액), `npm run build`.

## OpenAI 학습 도우미 (이슈 #5)

Node.js 20.19 이상을 사용합니다. `.env.example`을 프로젝트 루트의 `.env.local`로 복사하고 `OPENAI_API_KEY`를 로컬 편집기에서 입력한 뒤 개발 서버를 다시 시작하세요. 키를 채팅이나 Git에 넣지 마세요. `OPENAI_MODEL` 기본값은 `gpt-4.1-mini`입니다.

```sh
npm run dev -- --host 127.0.0.1 --port 5174
```

- **실시간 도움말:** 기본 설명 → ‘궁금한 버튼 고르기’ → 화면의 버튼 선택 → ‘AI 설명 요청하기’. 설명을 고르는 동안 주문 상태는 바뀌지 않습니다.
- **상황별 가이드:** 화면이 보이는 상태에서 30초간 조작이 없으면 도움말을 제안합니다. ‘같이 따라해보기’는 진행 가능한 다음 버튼 또는 선택 영역을 강조합니다. 선택이나 결제를 대신 실행하지 않습니다.
- **체험 피드백:** 화면이 보인 시간, 단계 재방문, 도움말 열기 횟수와 현재 주문을 바탕으로 설명합니다. 긴 체류 시간을 오류로 판정하지 않습니다. AI 설명 버튼을 눌렀을 때만 외부 API를 호출합니다.
- **학습 리포트:** 완료 버튼을 누른 연습만 `localStorage`에 저장합니다. 홈에서 최근 기록, 도움 요청과 재방문이 많은 단계, 추천 연습을 확인하고 전체 기록을 삭제할 수 있습니다. 중간 종료한 주문은 저장하지 않습니다.
- **실패 처리:** 키 미설정, 네트워크·시간 초과, 모델 오류, 호출 제한 시 기본 안내를 유지합니다. 생성된 답변과 기본 안내는 화면에서 구분합니다. 기록 저장이 차단된 브라우저에서도 현재 결과는 볼 수 있습니다.

서버의 `/api/ai`가 [OpenAI Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)를 호출합니다. 키는 Vite의 브라우저 환경변수(`VITE_*`)로 노출하지 않습니다. 요청은 현재 선택과 화면 버튼, 단계 기록만 포함하며 `store: false`로 전송합니다. 입력 크기·형식·출처 검사, 서버 전체 분당 20회·동시 2회 제한, 15초 상위 API 제한을 적용합니다.

개발 서버와 `npm run preview -- --host 127.0.0.1`에 같은 API 미들웨어가 연결됩니다. **현재 서버는 로컬 실행용입니다.** 정적 `dist`만 배포하면 AI API는 동작하지 않습니다. 공개 서비스 배포 시 별도 서버에서 이 미들웨어를 제공하고 인증과 사용자별 비용 제한을 추가해야 합니다. API 키가 연결되면 OpenAI 사용 요금이 발생합니다.

검증: `npm test`는 기존 주문 계산·좌석 테스트와 학습 기록 누적/손상/저장 제한, AI 요청 검증·성공·실패·호출 제한을 확인합니다. 실제 OpenAI 호출은 키가 있는 환경에서 별도로 확인해야 합니다.
